## Object-Oriented Programming (OOP) Pillars Explained

- **Abstraction**: Hides complex internal implementation details and shows only necessary features using abstract classes (`ABC`) and methods (`@abstractmethod`).
- **Encapsulation**: Restricts direct access to data by keeping attributes private (`__name`, `__roll_no`) and providing public getter methods (`get_name()`, `get_roll_no()`) to access them safely.
